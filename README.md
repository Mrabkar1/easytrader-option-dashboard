# داشبورد رصد بازار آپشن EasyTrader

داشبورد محلی برای پایش بازار آپشن «کارگزاری مفید / EasyTrader» — موقعیت‌ها، سود/زیان، کل زنجیرهٔ قراردادها، سفارش‌ها و موجودی، همگی روی `localhost`.

> ⚠️ **فقط خواندن.** این داشبورد هیچ سفارشی ثبت، تغییر یا حذف نمی‌کند؛ تنها داده‌ها را نمایش می‌دهد.

## امکانات
- 📊 خلاصه: سود/زیان باز و بسته، موجودی، شاخص کل، تعداد موقعیت
- 📍 موقعیت‌های باز به تفکیک قرارداد
- 🔗 زنجیرهٔ آپشن (بیش از ۱۸۰۰ قرارداد) با جستجوی سریع (کال/پوت، قیمت اعمال، ISIN)
- 🧾 سفارش‌های فعال در جریان
- 🔐 توکن نشست فقط روی سیستم خودتان (`auth.json`)؛ هیچ داده‌ای به سرور دیگری نمی‌رود
- 🕊 رفرش خودکار ملایم (۴۵ ثانیه) با backoff در خطا، کش سمت سرور (زنجیره با TTL ۱۰ دقیقه) و محدودیت فاصلهٔ بین درخواست‌های خروجی تا وب‌سایت پُروفشار نشود

## نصب و اجرا
پیش‌نیاز: **[Python 3.10+](https://python.org)** — بدون هیچ وابستگی pip.

```cmd
run.bat
```

با باز شدن مرورگر روی `http://127.0.0.1:8787`، تب توکن را دنبال کنید:
1. وارد `d.easytrader.ir` شوید و لاگین کنید.
2. از صفحهٔ `/get-token`، بوکمارکلت را به نوار بوکمارک بکشید.
3. روی وب‌سایت، بوکمارکلت را کلیک کنید — توکن طی یک redirect امن (در فرگمنت `#`) به سرور محلی می‌رسد.

توقف: `stop.bat` یا بستن پنجرهٔ Python.

### اجرای خودکار با ویندوز
شورتکاتی از `run.bat` در پوشهٔ `shell:startup` بگذارید تا پس از هر بار روشن‌شدن سیستم، داشبورد آماده باشد.

## نکته‌های امنیتی
- `auth.json` صرفاً محلی است و **به‌هیچ‌وجه نباید** به گیت یا مکانی دیگر منتقل شود (در `.gitignore` است).
- توکن معمولاً هم‌روز منقضی می‌شود؛ پس از انقضا دوباره بوکمارکلت را اجرا کنید.
- حذف حساب: فایل `auth.json` را پاک کنید.

## ساختار
```
easytrader-app/
├── server.py        ← وب‌سرور + پروکسی API با کش و rate-limit
├── dashboard.html   ← رابط کاربری
├── static/          ← app.js و style.css
├── get-token.html   ← راهنمای دریافت توکن (بوکمارکلت)
├── save-token.html  ← نقطهٔ ورود توکن پس از redirect
├── run.bat / stop.bat
```

## عیب‌یابی
| نشانه | راه‌حل |
|---|---|
| «سرور در دسترس نیست» | `run.bat` را اجرا کنید |
| «توکن منقضی شده» | دوباره لاگین + بوکمارکلت |
| پورت 8787 اشغال است | `stop.bat` بزنید سپس `run.bat` |
